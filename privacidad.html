Qué datos trata esta web

La web no tiene formularios, cuentas, newsletter ni analítica. No recoge datos personales por sí misma; solo los recibimos si nos escribes o llamas.

Alojamiento

El servidor que aloja la web puede registrar datos técnicos (dirección IP, fecha y hora, página solicitada) para entregar el contenido y proteger el servicio.

Correo para fotocopias

Si nos envías un archivo para fotocopiar, trataremos tu dirección de correo y el contenido del documento solo para realizar el trabajo y avisarte. Borraremos el mensaje y el archivo una vez recogido el pedido. No envíes documentos con datos especialmente sensibles si no es necesario.

Llamadas

Si llamas por teléfono, tu número será visible para el establecimiento solo para atender tu consulta.

Derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación y portabilidad ante el responsable. También puedes reclamar ante la Agencia Española de Protección de Datos (aepd.es).

Servicios externos

El mapa de Google Maps está incrustado pero no se carga hasta que pulsas «Cargar mapa»; hasta entonces no se conecta con Google. Al cargarlo, Google puede recibir tu IP y usar cookies bajo su propia política (policies.google.com/privacy). Los enlaces «Cómo llegar» y de reseñas también salen a Google Maps.
